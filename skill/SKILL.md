# 创意面板（creative-panel）

## 这是什么

一个只记两样东西的账本：**一个创意**，和**它走到哪一步**。

```
仅有创意 idea  →  正在明确 clarifying  →  已经明确 clarified  →  正在制作 building  →  完成成品 done
```

**面板是账本，不是执行器。** 这条是这个 skill 的全部前提：

- 你（agent）是驱动方，面板是被写入的一侧。**面板不会主动去调任何别的 skill**，
  你在面板上看到「正在制作」，不代表有什么东西正在跑——那是你上次推进时写下的字。
- 具体干活（出图、做视频、写稿）由别的 skill 负责。本 skill 只改面板上的状态和文字。
- 面板不存素材文件本身，只存文字描述和标签。成品在哪、怎么归档，是那些 skill 的事。

## 什么时候用这个 skill

**该用：**

- 用户冒出一个想法，让你先记下来（哪怕现在什么细节都还没有）
- 某个创意要往前推一步（需求聊清楚了 / 方案定了 / 开始做了 / 做完了）
- 要看现状：有哪些卡住了、有哪些在制作中、某张卡的时间线是什么
- 用户在浏览器里拖了卡片、标了阻塞，你想让 agent 接着往下做

**不该用：**

- 用户要你**做出**什么东西（一张图、一段视频、一篇稿）——那是别的 skill 的活。
  本 skill 最多在动手前后各记一笔状态。
- 要**存文件 / 传附件 / 在线预览素材**——面板没有这个功能（SPEC 第 12 节明确排除）。
- 要**管多人任务、权限、项目分组**——本面板是纯本机单人用的，不做账号和权限。

## 前置：两样东西都得先在

| 要什么 | 在哪 | 没有的话 |
| --- | --- | --- |
| 面板服务 | `127.0.0.1:8472` | 请用户双击项目根目录的 `start.bat`。未启动时任何命令都会报「面板未启动，请双击 start.bat」并退出码 1 |
| CLI | 本 skill 目录下的 `panel.py` | 用户还没跑过 `install_skill.bat` 时，先请用户跑一次 |

本机路径（用户换了机器就跟着 `USERPROFILE` 变）：

```
解释器: C:\ProgramData\anaconda3\python.exe
CLI:    C:\Users\dy120\.minimax\skills\creative-panel\panel.py
```

下面的示例统一写成 `panel.py`，实际调用时把上面那两条填进去：

```bat
"C:\ProgramData\anaconda3\python.exe" "C:\Users\dy120\.minimax\skills\creative-panel\panel.py" stats
```

输出是**给人看的中文**，不是 JSON。成功退出码 0，失败退出码 1 且只打一句人话，
不打 Python 栈——所以你在 bash 里执行时记得看退出码，别只看有没有 stdout。

## 命令

一共 9 个。状态可以写英文 key，也可以写中文显示名，两种都合法。

```bat
panel.py new "<标题>" [--body "<描述>"] [--tags a,b] [--source "<来源>"]   REM 记一条新创意
panel.py list [--status <态>] [--tag <标签>] [--q <关键词>] [--blocked]     REM 看列表，可叠加筛选
panel.py show <id>                                                          REM 看详情 + 完整时间线
panel.py advance <id> <状态> [--note "<这步做了什么>"]                     REM 往前推状态
panel.py note <id> "<消息>"                                                 REM 加一条备注，不改状态
panel.py block <id> "<卡住的原因>"                                         REM 标记卡住
panel.py unblock <id>                                                       REM 解除卡住
panel.py stats                                                              REM 五列各几张 + 阻塞数
panel.py delete <id>                                                        REM 删一张卡（events 一并删）
```

要点：

- `advance` **可以跨级跳**（`idea` 直接到 `building` 合法），但跳过的状态在流转轨上
  一律算「已过」。
- 推进到**当前状态**会被服务端拒（422），CLI 翻成「#12 已经在『正在明确』了」。
  看到这句说明你把同一步推进了两次，不是出错。
- `block` 可以重复调，每次覆盖原因并**都**记一条事件——原因变了就值得留痕。
- `unblock` **不清**卡片上的原因文字，历史原因在 `show` 的时间线里。
- `list --blocked` 只看卡住的；`--q` 对标题和描述做关键词匹配，多个词是 AND。
- 改标题/描述/标签**没有 CLI 子命令**，那是浏览器端的活（网页上直接编辑）。

## 标准工作流

用户说「我有个想法…」时，走这五步，**每一步都对应一次 CLI 调用**：

1. **记下来** → `new "<标题>"`，状态自动是 `idea`。用户只说了个念头、细节全没有，
   这时候不要追着问，先记下来。手上已经有的背景（为什么想做、给谁看）用
   `--body` 一并写进去，别只留一个光秃秃的标题。
2. **开始明确** → `advance <id> clarifying --note "开始明确：需要确认目标受众和时长"`。
3. **方案定了** → `advance <id> clarified --note "定了 6 段 H3，每段 90 秒"`。
4. **开始做** → 调对应的 skill 去做东西，做之前
   `advance <id> building --note "开始生成第 1-2 段"`。
5. **交付完** → `advance <id> done --note "6 段全部交付，文件在 ..."`。

> **描述正文只能由人在网页上补。** 当前 CLI 没有 `edit` 子命令
> （SPEC 第 6 节的命令表里就没有），agent 只能改状态、备注和阻塞。
> 聊出来的需求正文**先记进 `--note`**，别指望回头补——note 会进时间线，不会丢。
> 要改标题/描述/标签，请用户在网页抽屉里编辑。

做不下去：`block <id> "<原因>"`。原因要写清楚是「等用户确认 X」还是「工具报错 Y」，
因为几天后回来看的很可能只有这句话。

## 铁律

- **每推进一步都带 `--note`，说清这步做了什么。** 时间线是给人读的，
  一串空的推进记录等于没记。
- **不许在没经用户确认的情况下直接跳到「完成成品」。** `done` 意味着有成品交付了，
  不是「差不多了」。
- **做不下去就 `block` 写清原因**，不要硬撑，也不要悄悄跳过——卡在面板上比消失在
  对话里有用。
- **不要替用户做决定。** 面板记的是用户的创意和用户的进度，不是 agent 的待办清单。
  用户没提的需求不要自己加进面板。
- **不要用面板存不该存的东西**：密码、token、私人账号这类内容不进 `body`。

## 失败了看什么

CLI 只打一句人话。按这句话对号入座：

| 看到的话 | 说明 | 怎么办 |
| --- | --- | --- |
| `面板未启动，请双击 start.bat` | 连不上 8472 | 请用户双击项目里的 `start.bat`；先自己 `stats` 试一次 |
| `标题不能为空` | `new` 的标题是空串 | 标题是必填的，哪怕只有一个词 |
| `未知状态：xxx（合法值：idea, clarifying, ...）` | 状态名拼错 | 只能用这 5 个 key |
| `#12 已经在『正在明确』了` | 重复推进同一状态 | 无需处理，状态已经是你想要的 |
| `没有 #99 这条创意` | id 不存在，或已被删除 | 用 `list` 重新查 id |
| `面板返回的...不是预期格式...` | `PANEL_URL` 指到了别的服务 | 检查环境变量 `PANEL_URL` |
| `面板内部错误（HTTP 500）` | 服务端崩了 | 退出码非 0，把原文给用户，让他看 `start.bat` 的窗口 |

所有失败都是**退出码 1**。如果你在脚本里连着调多条命令，别把失败当成功继续往下走。

两个环境变量，测试时才需要动，日常不用管：

- `PANEL_URL`：面板地址，缺省 `http://127.0.0.1:8472`
- `PANEL_DB`：数据库文件路径，缺省 `<项目根>/data/panel.db`

## 改这个 skill 的时候

**改项目里的 `skill\`，别直接改安装目录里的副本。**
`%USERPROFILE%\.minimax\skills\creative-panel\` 是安装产物，用户跑一次
`install_skill.bat` 就会被整体覆盖，直接改那里等于没改。
