# 创意面板

一个只记两样东西的本地记账面板：**一个创意**，和**它走到哪一步**。

```
仅有创意 → 正在明确 → 已经明确 → 正在制作 → 完成成品
```

不是任务管理器，不是素材库，不联网，没有账号。数据就一个 SQLite 文件在你本机。

---

## 快速开始

**第一次用**，两步：

1. 双击 **`start.bat`**
   窗口会打印地址，浏览器自动打开 <http://127.0.0.1:8472>，五列看板就在那儿。
   **这个窗口不要关**——它就是服务本身，关窗口等于停服务。

2. 双击 **`install_skill.bat`**
   把 agent 用的 skill 装到 `%USERPROFILE%\.minimax\skills\creative-panel\`。
   装完**新开一轮对话**才会生效。

> 没装第 2 步的话，面板照样能用（网页是给人操作的），只是 agent 不会往里写。

### 日常怎么用

- **网页**：双击 `start.bat`，浏览器打开就能用。拖卡片、搜索、筛标签、点开看时间线。
- **agent**：直接跟它说「记一下我这个想法」或「创意面板上还剩什么」，它会调用 skill
  往面板里写。前提是 `install_skill.bat` 跑过。

## 五个状态是什么意思

| 状态 | 含义 | 什么算进去了 | 什么还不算 |
| --- | --- | --- | --- |
| 仅有创意 `idea` | 只有个念头 | 一句话标题 | 任何明确的需求 |
| 正在明确 `clarifying` | 在聊清楚要做什么 | 正在问问题、查资料 | 已经定下来的方案 |
| 已经明确 `clarified` | 需求/方案定了，可以开做 | 目标、形式、规模都定了 | 任何成品 |
| 正在制作 `building` | 正在做 | 已经开始动手 | 已交付的东西 |
| 完成成品 `done` | 有交付物了 | 东西做好了并且交了 | —— |

五个状态是**固定、线性**的，不能改名字、不能加列、也不能配置（这是有意的，见 SPEC 第 12 节）。

- 可以**跳级**：`idea` 直接到 `building` 是合法的。被跳过的状态在流转轨上一律算「已过」。
- 不能**倒退到当前状态**：重复推进同一步会被拒绝，提示「#12 已经在『正在明确』了」。
- **卡住**是另一回事：任何状态都能标「卡住」，卡住时流转轨上只有当前那个点变红，
  进度不会因为卡住而丢失。

### 卡片左边那条竖轨

每张卡片左缘是**五格竖直的流转轨**，是本面板区别于普通看板的地方：

```
   │█│  idea        已过   实心
   │█│  clarifying  已过   实心
   ├◉┤  building    当前   发光圆点   ← 发光
   └┊┘  done        未到   虚线
```

**不点开卡片就能看出它走到哪一步。** 每格用它自己那一态的颜色，所以整条轨
本身就是一条进度光谱。卡片卡住时只有当前那个点变红并给卡片加一道红边，
**不会把整条轨涂红**——那样就看不出走到哪一步了，这条轨也就没意义了。

## agent 是怎么往面板里写的

**agent 是驱动方，面板是被写入的一侧。面板不会主动去调别的 skill**——
你在面板上看到「正在制作」，不代表有什么东西正在跑，那只是上次推进时写下的字。
出图、做视频、写稿由别的 skill 负责，面板只负责记账。

装好 skill 后，agent 用的命令长这样（真实路径按本机 `USERPROFILE` 换）：

```bat
"C:\ProgramData\anaconda3\python.exe" "%USERPROFILE%\.minimax\skills\creative-panel\panel.py" new "AI 发展史短片系列" --tags 视频,科普
```

日常对话里不用敲这些，直接说「记一下我这个想法：……」就行。完整命令表见
[`skill/SKILL.md`](skill/SKILL.md)。

界面上人和 agent 的分工：

| 谁 | 干什么 |
| --- | --- |
| 人（浏览器） | 拖拽推进、编辑标题/描述/标签、标卡住、排序 |
| agent（CLI） | 记新创意、推进状态、加备注、标卡住、看列表和统计 |

时间线里会记下**是谁**做的操作（`你` / `agent`），所以一眼能看出哪一步是人推的、哪一步是 agent 推的。

## 文件在哪

| 是什么 | 在哪 |
| --- | --- |
| 项目代码 | `D:\coding\creative-panel\` |
| 数据（**你的全部内容都在这儿**） | `D:\coding\creative-panel\data\panel.db` |
| 前端（三个文件，零 CDN，可直接改） | `web\index.html` / `app.js` / `style.css` |
| 后端 | `server\app.py`（路由）、`store.py`（逻辑）、`db.py`（表结构） |
| agent 用的 skill **源文件** | `skill\SKILL.md` + `skill\panel.py` |
| skill 的**安装副本** | `%USERPROFILE%\.minimax\skills\creative-panel\` |

### 数据在哪、怎么备份

**全部内容在 `data\panel.db` 这一个文件里**（创意 + 它们的全部时间线）。
`data\` 目录不入版本库。

备份就是把整个 `data\` 目录复制走：

```bat
xcopy data D:\backup\panel-data\ /E /I
```

恢复：把 `panel.db` 拷回去，覆盖掉现有的那个，再重启 `start.bat`。

> 面板是本机单人用的，没有账号也没有权限，**任何能读这个文件的人都能读到你全部内容**。
> 别把 `data\` 目录传到网上。

## 常见问题

**双击 `start.bat` 窗口一闪就没了**
窗口停在后台了，或者被别的程序挡住了。看任务栏。最常见的原因是 Python 路径不对——
脚本里写死了 `C:\ProgramData\anaconda3\python.exe`，本机 PATH 里那个 `python` 不是它。

**提示端口 8472 被占用**
本机另一个项目 media-center-pms 用的是 8471，本面板是 8472，两个不冲突。
8472 被占说明**面板很可能已经在跑**（`start.bat` 会自己检查并直接开浏览器）；
若不是，关掉占用它的程序再双击。

**`panel.py` 报「面板未启动，请双击 start.bat」**
服务没起，或起在了别的地址。环境变量 `PANEL_URL` 可以覆盖地址，默认就是
`http://127.0.0.1:8472`。

**改了 skill 没生效**
改的位置不对。`%USERPROFILE%\.minimax\skills\creative-panel\` 是**安装产物**，
跑一次 `install_skill.bat` 就被覆盖。要改请改项目里的 `skill\`，改完重跑
`install_skill.bat`，然后新开一轮对话。

**网页打不开但 `start.bat` 没报错**
用 <http://127.0.0.1:8472/api/health> 探一下，正常应该返回 `{"ok":true,...}`。

## 开发

```bat
"C:\ProgramData\anaconda3\python.exe" -m pytest test_panel.py -q
```

测试全走真实 HTTP：用临时端口起真服务端、用 `tmp_path` 建临时库，
**绝不会碰 `data\panel.db`**。

**前端没有自动化测试**——这是「零 CDN + 无构建步骤」这条约束的直接后果，不是遗漏。
所以改 `web/` 之后只能靠真实浏览器看一眼：五列渲染出来、控制台无报错、拖拽能用。

设计规格在 `docs/superpowers/specs/2026-10-12-creative-panel-design.md`，
代码里的注释大量引用它的章节号。
